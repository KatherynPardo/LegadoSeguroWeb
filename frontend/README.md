# Frontend: LegadoSeguro

Aplicación Angular del proyecto. La descripción general, el manual de construcción y la puesta en marcha están en el [README principal](../README.md) y en [MANUAL_CONSTRUCCION.md](../MANUAL_CONSTRUCCION.md).

```bash
npm install
ng serve
```

Se abre en http://localhost:4200 y necesita el backend encendido en el puerto 5000.
